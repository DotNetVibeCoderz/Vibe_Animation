# NiceViz - Audio Visualizer 🎵✨

*[English Version Below]*

## 🇮🇩 Bahasa Indonesia

**NiceViz** adalah aplikasi simulasi visualisasi audio sederhana namun elegan yang dibangun menggunakan **C#** dan **Windows Forms** (.NET 9). Proyek ini dirancang untuk mendemonstrasikan bagaimana membuat grafik animasi yang halus (60 FPS) dengan teknik menggambar GDI+.

Dibuat dengan ❤️ oleh **Jacky the Code Bender** (Gravicode Studios).

### ✨ Fitur Utama
Aplikasi ini memiliki 3 mode visualisasi yang dapat diganti secara real-time:

1.  **Spectrum Bars**: Grafik batang klasik ala Winamp dengan pewarnaan gradasi dari Cyan ke Magenta.
2.  **Digital Wave**: Gelombang garis ala osiloskop dengan efek *glow* (bersinar).
3.  **Neon Pulse**: Lingkaran di tengah yang berdenyut sesuai simulasi "bass", dikelilingi partikel yang bereaksi.

### 🛠️ Teknologi
-   **Bahasa**: C#
-   **Framework**: .NET 9.0 (Windows Forms)
-   **Grafis**: GDI+ (System.Drawing) dengan *Double Buffering* untuk mencegah kedipan (flicker).

### 🚀 Cara Menjalankan
Pastikan Anda sudah menginstall **.NET 9 SDK**.

1.  Buka terminal/command prompt di folder project.
2.  Jalankan perintah berikut:
    ```bash
    dotnet run
    ```
3.  Nikmati visualisasinya! Klik tombol **"Switch Mode"** di pojok kiri atas untuk mengganti tampilan.

## 🇺🇸 English

**NiceViz** is a simple yet elegant audio visualization simulation app built with **C#** and **Windows Forms** (.NET 9). This project is designed to demonstrate how to create smooth animated graphics (60 FPS) using GDI+ drawing techniques.

Crafted with ❤️ by **Jacky the Code Bender** (Gravicode Studios).

### ✨ Key Features
The app features 3 visualization modes switchable in real-time:

1.  **Spectrum Bars**: Classic Winamp-style bar graph with Cyan-to-Magenta gradient coloring.
2.  **Digital Wave**: Oscilloscope-style line wave with a glowing effect.
3.  **Neon Pulse**: A central circle that pulses to the simulated "bass", surrounded by reactive particles.

### 🛠️ Tech Stack
-   **Language**: C#
-   **Framework**: .NET 9.0 (Windows Forms)
-   **Graphics**: GDI+ (System.Drawing) with *Double Buffering* to prevent flickering.

### 🚀 How to Run
Make sure you have the **.NET 9 SDK** installed.

1.  Open your terminal/command prompt in the project folder.
2.  Run the following command:
    ```bash
    dotnet run
    ```
3.  Enjoy the visuals! Click the **"Switch Mode"** button in the top-left corner to change the view.
