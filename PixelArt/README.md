## Deskripsi Proyek
Pixel Art Motivator adalah aplikasi Windows Forms sederhana namun estetis yang menampilkan efek visual "jadul" (retro) dengan gaya Pixel Art. Aplikasi ini dibuat untuk memberikan inspirasi melalui kutipan-kutipan motivasi sambil memanjakan mata dengan efek grafis klasik.

Aplikasi ini rmerupakan surat cinta untuk masa lalu koding, di mana pengembang game dan demo harus kreatif dengan keterbatasan resolusi dan kinerja.

## Fitur Utama
1. **Efek Visual Retro**:
   - **Starfield**: Simulasi perjalanan luar angkasa 3D klasik.
   - **Doom Fire**: Algoritma efek api legendaris yang digunakan dalam game Doom.
   - **Matrix Rain**: Efek hujan digital berwarna hijau a la The Matrix.
   
2. **Kutipan Motivasi**:
   - Menampilkan kutipan inspiratif yang berganti-ganti secara otomatis.
   - Efek transisi *fade-in* yang halus untuk teks.

3. **Rendering Pixel Perfect**:
   - Menggunakan resolusi internal rendah (160x120) yang di-*scale up* ke ukuran jendela.
   - Menggunakan interpolasi `NearestNeighbor` untuk menjaga ketajaman piksel (tampilan kotak-kotak yang tajam).

4. **Sistem Scene Otomatis**:
   - Efek visual berganti secara otomatis setiap 8 detik agar pengguna tidak bosan.

## Cara Menjalankan
1. Pastikan Anda memiliki .NET 9.0 SDK terinstal.
2. Buka terminal atau command prompt di dalam folder proyek.
3. Jalankan perintah:
   ```bash
   dotnet run
   ```
4. Nikmati pertunjukannya!

## Project Description
Pixel Art Motivator is a simple yet aesthetic Windows Forms application showcasing "retro" visual effects in Pixel Art style. It is designed to inspire you with motivational quotes while treating your eyes to classic graphic effects.

This application is a love letter to the coding past, where game and demo developers had to be creative within the constraints of resolution and performance.

## Key Features
1. **Retro Visual Effects**:
   - **Starfield**: A classic 3D space travel simulation.
   - **Doom Fire**: The legendary fire effect algorithm used in the game Doom.
   - **Matrix Rain**: The green digital rain effect inspired by The Matrix.

2. **Motivational Quotes**:
   - Displays inspiring quotes that rotate automatically.
   - Smooth text fade-in transition effects.

3. **Pixel Perfect Rendering**:
   - Uses a low internal resolution (160x120) scaled up to the window size.
   - Uses `NearestNeighbor` interpolation to maintain pixel sharpness (crisp blocky look).

4. **Automatic Scene System**:
   - Visual effects switch automatically every 8 seconds to keep things fresh.

## How to Run
1. Ensure you have the .NET 9.0 SDK installed.
2. Open a terminal or command prompt inside the project folder.
3. Run the command:
   ```bash
   dotnet run
   ```
4. Enjoy the show!
