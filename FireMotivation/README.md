## 🇮🇩 Bahasa Indonesia

### Deskripsi Proyek
**FireMotivation** adalah aplikasi visualisasi motivasi yang menampilkan efek animasi api yang realistis (gaya retro) disertai dengan kata-kata mutiara yang berganti secara otomatis. Aplikasi ini dirancang untuk memberikan semangat membara kepada penggunanya saat dipandang.

Dibuat menggunakan **C#** dan **Windows Forms** dengan teknik rendering grafis berkinerja tinggi (menggunakan manipulasi bitmap pointer).

### Fitur Utama
- **Animasi Api Realistis**: Simulasi fisika api menggunakan *heat map* dan palet warna kustom.
- **Kata-kata Motivasi**: Tampilan kutipan motivasi yang muncul dan menghilang (*fade in/out*) secara halus.
- **Mode Layar Penuh**: Aplikasi berjalan dalam mode *fullscreen* tanpa *border* untuk pengalaman imersif.
- **Performa Tinggi**: Menggunakan *unsafe code* dan *bitmap buffering* untuk rendering yang mulus.

### Cara Menjalankan
1. Pastikan komputer Anda telah terinstal **.NET 8.0 SDK** atau yang lebih baru.
2. Buka terminal atau command prompt di folder proyek.
3. Jalankan perintah berikut:
   ```bash
   dotnet run
   ```
4. Aplikasi akan terbuka dalam mode layar penuh.

### Kontrol
- **ESC**: Tekan tombol `ESC` pada keyboard untuk keluar/menutup aplikasi.

### Teknologi
- **Language**: C#
- **Framework**: .NET 8.0 (Windows Forms)
- **Rendering**: GDI+, Bitmap Manipulation (Unsafe Code)

## 🇬🇧 English

### Project Description
**FireMotivation** is a motivational visualization application that displays a realistic fire animation effect (retro style) accompanied by automatically cycling inspirational quotes. This app is designed to ignite the user's spirit when viewed.

Built using **C#** and **Windows Forms** with high-performance graphics rendering techniques (using pointer bitmap manipulation).

### Key Features
- **Realistic Fire Animation**: Fire physics simulation using a heat map and custom color palette.
- **Motivational Quotes**: Displays quotes that fade in and out smoothly.
- **Fullscreen Mode**: Runs in borderless fullscreen mode for an immersive experience.
- **High Performance**: Uses unsafe code and bitmap buffering for smooth rendering.

### How to Run
1. Ensure your computer has **.NET 8.0 SDK** or newer installed.
2. Open a terminal or command prompt in the project folder.
3. Run the following command:
   ```bash
   dotnet run
   ```
4. The application will open in fullscreen mode.

### Controls
- **ESC**: Press the `ESC` key on your keyboard to exit/close the application.

### Tech Stack
- **Language**: C#
- **Framework**: .NET 8.0 (Windows Forms)
- **Rendering**: GDI+, Bitmap Manipulation (Unsafe Code)
