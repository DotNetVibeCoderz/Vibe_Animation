# MathArt 🎨
Beautiful Mathematical Animations using C#, Avalonia UI, and SkiaSharp.

## 🇺🇸 English
MathArt is an application showcasing generative art and mathematical animations. It translates complex mathematical formulas into smooth and beautiful animations using Avalonia UI and SkiaSharp.

### Features:
- **Various Math Art Visualizations**:
  - Lissajous Curve
  - Generative Wave
  - Polar Flower
  - Algorithmic Spiral Grid
  - Fibonacci Spiral
  - Concentric Circles
  - Random Walk (Drunken Artist)
- **Cross-Platform**: Runs natively on Windows, macOS, and Linux.
- **Smooth Animations**: Hardware-accelerated rendering (~60fps) using SkiaSharp.
- **Fullscreen Mode**: Easily toggle between windowed and fullscreen with a single click.

### How to Run:
Ensure you have [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) installed.
1. Open the terminal or command prompt.
2. Navigate to the project directory.
3. Run `dotnet run`.

## 🇮🇩 Bahasa Indonesia
MathArt adalah aplikasi yang menampilkan seni generatif dan animasi matematika. Aplikasi ini menerjemahkan rumus matematika yang kompleks ke dalam bentuk animasi yang mulus dan indah menggunakan Avalonia UI dan SkiaSharp.

### Fitur:
- **Berbagai Visualisasi Seni Matematika**:
  - Kurva Lissajous (Lissajous Curve)
  - Gelombang Generatif (Generative Wave)
  - Bunga Polar (Polar Flower)
  - Grid Spiral Algoritmik (Algorithmic Spiral Grid)
  - Spiral Fibonacci (Fibonacci Spiral)
  - Lingkaran Konsentris (Concentric Circles)
  - Perjalanan Acak (Random Walk)
- **Multi-Platform**: Dapat berjalan secara native di Windows, macOS, dan Linux.
- **Animasi Super Mulus**: Menggunakan akselerasi perangkat keras (~60fps) dengan SkiaSharp.
- **Mode Layar Penuh**: Mendukung tampilan layar penuh dan jendela secara interaktif melalui tombol toggle.

### Cara Menjalankan:
Pastikan Anda telah menginstal [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
1. Buka terminal atau command prompt.
2. Navigasikan ke folder proyek.
3. Jalankan `dotnet run`.
