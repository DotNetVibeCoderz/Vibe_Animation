# WaterApp 💧

![WaterApp](https://img.shields.io/badge/Language-C%23-blue) ![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey) ![License](https://img.shields.io/badge/License-MIT-green)

**(Bahasa Indonesia)**

WaterApp adalah aplikasi simulasi grafis berbasis Windows Forms yang menampilkan efek riak air (water ripple) yang realistis dan menenangkan. Dibuat dengan cinta oleh **Jacky the Code Bender** dari **Gravicode Studios**.

Aplikasi ini tidak hanya menampilkan simulasi fisika air, tetapi juga menyajikan kutipan-kutipan inspiratif yang muncul bergantian untuk menemani waktu santai Anda.

## Fitur Utama 🌟

*   **Simulasi Riak Air Realistis**: Menggunakan algoritma fisika air klasik untuk menghasilkan efek gelombang yang nyata.
*   **Interaktif**: Klik di mana saja pada layar untuk membuat riak air yang besar.
*   **Tetesan Hujan Otomatis**: Tetesan air akan jatuh secara acak menciptakan suasana kolam yang hidup.
*   **Kutipan Inspiratif**: Menampilkan kata-kata bijak yang muncul (fade-in) dan menghilang (fade-out) secara halus.
*   **Performa Tinggi**: Menggunakan *unsafe code* dan manipulasi *pointer* memori langsung (`Bitmap.LockBits`) untuk rendering grafis yang cepat dan mulus (60 FPS).
*   **Latar Belakang Prosedural**: Dasar kolam dibuat secara *generate* kode sehingga unik setiap kali dijalankan.

## Persyaratan Sistem 💻

*   Sistem Operasi: Windows 10/11
*   .NET SDK: .NET 9.0 (atau yang lebih baru)

## Cara Menjalankan 🚀

1.  Pastikan Anda telah menginstal .NET 9.0 SDK.
2.  Buka terminal atau Command Prompt.
3.  Arahkan ke direktori project ini.
4.  Jalankan perintah berikut:
    ```bash
    dotnet run
    ```
5.  Nikmati ketenangan kolam digital Anda!

**(English)**

WaterApp is a Windows Forms-based graphical simulation application that showcases a realistic and soothing water ripple effect. Crafted with love by **Jacky the Code Bender** from **Gravicode Studios**.

This application not only creates a fluid water physics simulation but also presents inspirational quotes that gently fade in and out to accompany your relaxation time.

## Key Features 🌟

*   **Realistic Water Ripple Simulation**: Uses classic water physics algorithms to produce lifelike wave effects.
*   **Interactive**: Click anywhere on the screen to create a splash and ripples.
*   **Auto Raindrops**: Random water droplets fall automatically, creating a lively pool atmosphere.
*   **Inspirational Quotes**: Displays wise words that smoothly fade in and out.
*   **High Performance**: Utilizes *unsafe code* and direct memory pointer manipulation (`Bitmap.LockBits`) for fast and smooth graphic rendering (target 60 FPS).
*   **Procedural Background**: The pool bottom is procedurally generated code, making it unique every run.

## System Requirements 💻

*   Operating System: Windows 10/11
*   .NET SDK: .NET 9.0 (or newer)

## How to Run 🚀

1.  Ensure you have .NET 9.0 SDK installed.
2.  Open your terminal or Command Prompt.
3.  Navigate to this project directory.
4.  Run the following command:
    ```bash
    dotnet run
    ```
5.  Enjoy your digital pool of tranquility!
